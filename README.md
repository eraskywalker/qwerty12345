# ЛПР4

## Назначение

Учебный статический сайт для практики HTML, CSS, JavaScript и работы с Git.

## Настройка разработки

1. Клонируйте репозиторий.
2. Откройте файл `index.html` в браузере или через локальный сервер.
3. Изменяйте исходные файлы в каталогах `assets/css` и `assets/js`.

## Руководящий документ

Версия ветки feature/conflict.

Правила работы с ветками и оформления коммитов приведены в документации проекта.
